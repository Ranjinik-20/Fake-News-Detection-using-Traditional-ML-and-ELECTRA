# Fake-News-Detection-using-Traditional-ML-and-ELECTRA
Fake News Detection using NLP and Machine Learning. This project compares Linear SVM, LSA with Gradient Boosting, and a fine-tuned ELECTRA model on the ISOT Fake News Dataset. Performance is evaluated using Accuracy, Precision, Recall, F1-score, ROC-AUC, and PR-AUC.
